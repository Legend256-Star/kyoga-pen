# Kyoga Pen CMS
Real news publishing system with admin login, SQLite database, image upload, drafts, publish/edit/delete, and public news pages.
Run: install Node.js 20+, then `npm install` and `npm start`. Open http://localhost:3000 and /admin.html.
For production hosting, use a Node.js host with persistent disk/storage for `kyoga.db` and `public/uploads`.
